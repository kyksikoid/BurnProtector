# Burn Protector

Android-приложение для снижения риска неравномерного износа AMOLED/OLED-экранов из-за статичных элементов интерфейса.

Приложение выводит защитные полосы по краям экрана. Их можно использовать, например, при длительном просмотре TikTok, Instagram, YouTube Shorts и других приложений, где одни и те же элементы интерфейса долго находятся на одном месте.

## Возможности

### Защитные полосы

Можно отдельно настроить размер полосы для:

* верхней части экрана;
* нижней части;
* левой и правой сторон.

Доступны несколько вариантов отображения:

* чёрный;
* белый;
* RGB;
* шум.

Для режима шума (и RGB) можно настроить частоту обновления.

### Пауза при касании

Если нажать на область защитной полосы, она временно скрывается. Это позволяет пользоваться элементами интерфейса, которые находятся под полосой.
Время скрытия настраивается в приложении.

### Выбор приложений

Можно указать приложения, в которых должны работать полосы.
Например, их можно включить только для TikTok и YouTube, а на рабочем столе и в остальных приложениях они не будут работать.

### Автозапуск приложения

При запуске защиты автоматически откроется выбранное приложение.

### Full Screen

Режим для восстановления пикселей при появлении временного остаточного изображения.
После запуска приложение полностью заполняет экран быстро меняющимся шумом или RGB-цветами. За счёт постоянного изменения изображения статичные участки экрана перестают долго отображать один и тот же цвет.
Режим запускается вручную и работает отдельно от защитных полос в настройках приложения.

### Режимы работы

Есть два варианта работы:

* **Non-Root** — через службу специальных возможностей Android;
* **Root** — отдельный режим для устройств с root-доступом.

## Требования

* Android 8.0 (API 26) или новее.
* Root не требуется для основного режима работы.

## Android 13+

На некоторых устройствах Android 13 и новее система может заблокировать включение службы специальных возможностей для приложения, установленного не из системного магазина.
Если переключатель службы недоступен и появляется сообщение:
> «В целях безопасности этот параметр недоступен»

нужно разрешить ограниченные настройки для приложения.

1. Настройки телефона → приложения → Burn Protector
2. Нажмите ⋮ (3 точки) в верхнем правом углу
3. Выберите «Разрешить ограниченные настройки»
4. Подтвердите паролем (если есть) и включите службу

P.S. Заодно можете включить «всегда сверху» (поверх других окон)

Названия пунктов могут немного отличаться в зависимости от производителя телефона и версии Android.

## Как это работает

В Non-Root режиме приложение использует службу специальных возможностей Android для управления отображением защитных областей поверх других приложений.

Для работы поверх других приложений также используются системные механизмы Android, поэтому конкретное поведение может отличаться на разных прошивках.

## Важно

Burn Protector не может гарантировать полное предотвращение выгорания или неравномерного износа OLED/AMOLED-экрана.

Результат зависит от типа дисплея, его настроек, яркости, времени использования и других факторов.

Приложение предназначено как дополнительная мера, а не как способ полностью исключить износ дисплея.
